# Git vs GitHub – সম্পূর্ণ গাইড

> **সংক্ষেপে:**  
> **Git** = কোডের পরিবর্তন ট্র্যাক করার টুল (লোকাল)  
> **GitHub** = সেই কোড অনলাইনে শেয়ার ও কোলাবোরেট করার প্ল্যাটফর্ম

---

## Git কী?

**Git** হলো একটি **Distributed Version Control System**।

এটা তোমার প্রজেক্টের প্রতিটা পরিবর্তন হিস্ট্রি হিসেবে সংরক্ষণ করে। কে কখন কী পরিবর্তন করেছে, কেন করেছে — সব রেকর্ড থাকে। তুমি চাইলে যেকোনো সময় পুরনো ভার্সনে ফিরে যেতে পারো।

### Git-এর মূল বৈশিষ্ট্য:
- সম্পূর্ণ **লোকাল** কাজ করে (ইন্টারনেট লাগে না)
- ব্রাঞ্চ (branch) তৈরি করে আলাদা আলাদা ফিচার ডেভেলপ করা যায়
- কমিট (commit) এর মাধ্যমে পরিবর্তন সেভ করা হয়
- টিমে কাজ করার সময় কনফ্লিক্ট ম্যানেজ করা সহজ

**তৈরি করেছেন:** লিনাস টরভাল্ডস (Linux-এর জনক)  
**বছর:** ২০০৫

---

## GitHub কী?

**GitHub** হলো Git-এর উপর ভিত্তি করে তৈরি একটি **ক্লাউড হোস্টিং প্ল্যাটফর্ম**।

এখানে তুমি তোমার Git রিপোজিটরি আপলোড করে রাখতে পারো, অন্যদের সাথে শেয়ার করতে পারো এবং একসাথে কোড লিখতে পারো।

### GitHub-এর মূল সুবিধা:
- রিমোট রিপোজিটরি হোস্ট করে
- Pull Request দিয়ে কোড রিভিউ করা যায়
- Issue Tracker দিয়ে বাগ ও টাস্ক ম্যানেজ করা যায়
- GitHub Actions দিয়ে CI/CD অটোমেশন
- স্টার, ফর্ক, ফলো — সোশ্যাল ফিচার
- প্রাইভেট ও পাবলিক রিপোজিটরি সাপোর্ট

**চালু হয়:** ২০০৮  
**মালিক:** Microsoft (২০১৮ সালে কিনে নেয়)

---

## Git আর GitHub-এর মূল পার্থক্য

| বিষয়              | Git                          | GitHub                          |
|-------------------|------------------------------|---------------------------------|
| **ধরন**           | সফটওয়্যার / টুল              | ওয়েব সার্ভিস / প্ল্যাটফর্ম     |
| **কাজের জায়গা**   | তোমার কম্পিউটার (লোকাল)     | ইন্টারনেট (ক্লাউড)             |
| **ইন্টারনেট**     | লাগে না                      | লাগে                            |
| **মূল কাজ**       | ভার্সন কন্ট্রোল              | কোড হোস্টিং + কোলাবরেশন        |
| **বিকল্প**        | Git-ই মূল                    | GitLab, Bitbucket, SourceHut   |
| **নির্ভরশীলতা**   | একা চলতে পারে                | Git ছাড়া চলে না                 |

### সহজ উদাহরণ:
- **Git** = তোমার নোটবুক (যেখানে তুমি লেখো)
- **GitHub** = সেই নোটবুকের অনলাইন লাইব্রেরি (যেখানে সবাই পড়তে ও এডিট করতে পারে)

## সাধারণ ওয়ার্কফ্লো

```bash
# ১. লোকাল রিপোজিটরি তৈরি
git init

# ২. ফাইল অ্যাড করা
git add .

# ৩. কমিট করা (পরিবর্তন সেভ)
git commit -m "Initial commit"

# ৪. GitHub-এ পাঠানো
git remote add origin https://github.com/username/repo-name.git
git push -u origin main
